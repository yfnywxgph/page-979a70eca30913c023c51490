品牌简介

小鸟云面向需要稳定跨境访问的个人与小团队，提供可订阅的机场节点与多协议客户端指引。服务定位是把开通、导入、换线三件事写清楚：选套餐获得订阅链接，在 Clash、Shadowrocket、v2rayNG 等客户端中更新节点，再按延迟与用途切换线路。

线路包含普通节点池与 IPLC 专线优化。基础流媒体与日常网页加速可由基础版覆盖；需要全节点原生解锁、游戏向专线或更多同时在线设备时，再对照旗舰版与团队版。小鸟云官方网站只发布订阅说明与客户端安装路径，不捆绑来路不明的安装包。

性能说明：节点按区域维护，高峰时段优先保证网页、会议与主流视频可用性。游戏与实时对战请优先选择标注 IPLC 的入口，并避免在同一账号上无节制多开超出套餐设备上限。

使用场景

流媒体与内容站点

基础版适合对画质与片源要求一般的剧集、音乐与资讯站点。若目标平台校验出口 IP 与解锁质量，请使用旗舰版或团队版中的原生解锁节点，并在客户端关闭可能干扰的全局规则后再测试。

游戏与实时对战

旗舰版写明 IPLC 专线游戏加速优化，适合对延迟和丢包更敏感的对战与更新下载。连接后先看延迟与丢包，而不是只看节点名称中的国家标签。

远程办公与学习

视频会议、代码托管、文献库与网盘同步依赖稳定隧道。团队版提供更高带宽节点与定制路由，便于把办公网段与娱乐流量分开。

多设备家庭共用

手机、电脑与平板同时在线时，请对照套餐台数：基础版 3 台、旗舰版 5 台、团队版 20 台。超出后新设备可能无法认证，需下线闲置会话或升级。

操作说明

在套餐对比中确认流量、设备数与解锁需求，完成开通后从小鸟云官方渠道复制订阅地址。请妥善保存链接，避免发到公开群组。

二、下载并安装客户端

按系统到本页客户端下载专区选择软件。Windows 与 macOS 常用 Clash 兼容客户端；Android 可用 Clash Meta 或 v2rayNG；iOS 常用 Shadowrocket 或同类订阅客户端。只通过官网指引或系统商店获取。

三、导入订阅并更新节点

打开客户端，新建或粘贴订阅 URL，执行更新。成功后应看到分区节点（普通池、流媒体、IPLC 等）。若列表为空，检查链接完整性与本地时间是否准确。

四、选择节点并验证

网页浏览可选普通线路；需要原生解锁时切换对应分组；游戏走 IPLC。连接后访问目标站点确认，再把常用规则保存为配置，避免每次从全局代理改起。

常见问题

小鸟云是什么？和普通 VPN 有何不同？

小鸟云是提供机场订阅的网络加速服务：你获得的是可更新的节点列表，而不是单一固定 App 内的线路。可按设备选用 Clash、Shadowrocket 等客户端，并在普通节点与 IPLC 之间切换，更适合同时有流媒体、游戏和办公需求的用户。

如何在小鸟云官网完成客户端下载与导入？

先开通套餐拿到订阅链接，再按本页「客户端下载」安装对应软件，最后在客户端里粘贴订阅并更新。iOS 用户需在商店获取客户端后手动添加订阅，Android 与桌面端同样以订阅 URL 为准，不要安装来源不明的破解包。

三个套餐该怎么选？流量不够怎么办？

轻度网页与基础流媒体选基础版；要全节点原生解锁、游戏 IPLC 和优先工单选旗舰版；设备多、需要高带宽与定制路由选团队版。当月流量用尽后可升级档位或等待周期重置，本页不提供自动无限流量。

为什么有的节点无法播放流媒体？

解锁能力与套餐绑定：基础版为解锁基础流媒体，全节点原生解锁在旗舰版与团队版。请切换到流媒体分组，关闭可能污染 DNS 的插件后再试。若仅个别节目失败，换同分组其他入口通常比反复重装客户端更有效。

同时在线设备超限会怎样？如何减少占用？

超出套餐台数时，新终端可能无法完成认证或会挤掉旧会话。在各客户端中断开不用的配置、避免同一订阅在模拟器与实体机重复登录，或升级到支持更多设备的档位。

小鸟云支持哪些协议？企业能否定制路由？

日常使用以 Clash 订阅为主，并可导出或兼容 V2Ray、Shadowsocks、Sing-box 等常见形式。团队版写明支持企业定制路由，适合把办公网段、开发环境与娱乐流量拆开；具体策略在开通后由客户经理对接，不在公开页展开内部网段细节。
